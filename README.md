Mitt WES120V-prosjekt

Dette er et minimalt Vite-prosjekt laget som en del av WES120V.

## Teknologi

- Vite

- HTML

- Node.js

- pnpm

## Installere og starte prosjektet

Installer avhengighetene med:

pnpm install

Start utviklingsserveren med:

pnpm dev

Deretter kan prosjektet åpnes på adressen som Vite viser i terminalen.

## Prosjektstruktur

Prosjektet bruker en enkel struktur med index.html som inngangspunkt for nettsiden.
